# Memora

Memora is a Jac CLI project.

## Prerequisites

Install the Jac toolchain from the [official installation guide](https://docs.jaseci.org/quick-guide/install/), then verify it:

```sh
jac --version
```

## Run

From the repository root:

```sh
jac install
jac run
```

The entry point is [`main.jac`](main.jac), and project configuration lives in [`jac.toml`](jac.toml).
